## 西海岸三个机房：这批套餐的主要战场

### 圣何塞：现在能买到的默认答案

属于 CC 机房（ColoCrossing）。测评数据里，电信去程直连圣何塞，延迟大约 160ms；联通走 AS4837，稳定性在这几个机房里口碑最好；移动偏高，个别节点会绕路。另有测评给出三网平均 180ms 左右，两个数字的差别来自运营商和测试时段，不必纠结哪一个更准。

圣何塞真正的优势在库存。1GB 这种最便宜的档位也能选到它，而 DC-02 从来不给 1GB 方案。预算只有二十来美元、又想要西海岸低延迟，这里是唯一不需要运气的选项。

### 西雅图：联通相对友好，评价分化明显

位置在西海岸偏北。部分测评显示延迟在 200ms 以内，也有用户认为实际体验不如圣何塞。同一价位下它没有明显优势，联通宽带用户可以拿测试 IP 和自己的线路对一下再决定，其他情况直接选圣何塞省事。

### 洛杉矶 DC-02：公认最好的那个，这批买不到

Multacom 机房，IP 属 AS35916，RackNerd 给这个节点做了 Asia Optimized 的线路定制，电信走 163、联通走 AS4837，晚高峰丢包率比一般美西机房低不少。测评延迟从 150ms 到 200ms 都有。社区反馈 74 开头的 IP 段流媒体解锁更好，有用户实测能开 Netflix、Disney+、Prime Video。

## 选错了能不能换机房、能不能换 IP

官方对迁移的说法分三种情况。多机房可选的套餐，可以开工单申请迁移到当时有货的机房，只有 1 次机会。固定机房的套餐，有用户反馈花 $5 能迁。低价套餐（低于 $10/年）比较难迁，从别的机房迁进洛杉矶 DC-02 也比较难，或者要付 $5。工单回复是最终口径，别把网上说法当承诺。
